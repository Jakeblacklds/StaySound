# StaySound Admin

Panel privado para altas manuales y control de acceso.

## Variables

```bash
NEXT_PUBLIC_SUPABASE_URL=
NEXT_PUBLIC_SUPABASE_ANON_KEY=
SUPABASE_SERVICE_ROLE_KEY=
ADMIN_EMAILS=you@example.com
```

## Desarrollo

```bash
npm install
npm run dev
```

En Vercel se despliega apuntando a `sites/admin`.
